# QUERYNEST 🔍
### An Interactive Database Engineering Workbench

**Understand. Analyze. Optimize.**

QUERYNEST is a developer-focused project designed to explore database structure, analyze SQL queries, experiment with indexing strategies, and understand transaction concurrency through practical demonstrations.

The goal is to turn database concepts into interactive experiments that help developers understand how databases behave and how their performance can be investigated.

> 🚧 **Project Status:** Initial development — features will be added incrementally.

## 🎯 Project Objectives

- Explore database schemas, tables, columns, and relationships.
- Analyze SQL queries and understand their execution plans.
- Compare query performance under different indexing configurations.
- Demonstrate transaction conflicts and deadlock detection.
- Visualize experimental results to make database behavior easier to understand.

## ✨ Planned Features

### 1. Schema Explorer
Inspect database tables, columns, keys, constraints, and relationships.

### 2. SQL Query Analyzer
Examine query execution plans and measure query performance.

### 3. Index Experiment Lab
Compare query execution before and after introducing selected indexes.

### 4. Transaction Lab
Simulate transaction conflicts, construct wait-for graphs, and detect deadlocks.

### 5. Performance Dashboard
Present query benchmarks and experiment results in an easy-to-understand format.

*Features will be implemented and tested progressively. This list describes the project roadmap, not completed functionality.*

- Primary and foreign keys

- Performance benchmarking

## 🎓 Project Motivation

QUERYNEST is being developed as a hands-on learning project to strengthen database management, SQL, backend development, and problem-solving skills.

The focus is on understanding the concepts behind the implementation, testing features with realistic experiments, and documenting the engineering decisions made throughout development.
